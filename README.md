CIN OCR Intelligence


Proof of concept d’intelligence documentaire locale pour l’extraction sécurisée et structurée de données depuis des spécimens fictifs de CIN marocaine.

Contexte

Ce dépôt documente une étude de cas technique consacrée à la lecture automatisée du recto d’une Carte Nationale d’Identité marocaine, exclusivement à partir de spécimens fictifs. L’objectif est de construire une application web TypeScript capable d’extraire des données structurées tout en appliquant des règles strictes de confidentialité, de validation et de non-invention.


Aucune pièce d’identité réelle, aucune photographie réelle et aucune donnée personnelle réelle ne doivent être ajoutées à ce dépôt.

Objectif fonctionnel

L’application devra permettre à un utilisateur d’importer une image fictive, de contrôler sa validité, de lire localement son contenu OCR, puis de restituer un objet JSON contenant exactement les cinq champs suivants.
